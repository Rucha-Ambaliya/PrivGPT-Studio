# Privacy Controls Test Suite

Minimal test validation for conversation-level privacy controls.

## Quick Test
```bash
python test_privacy_feature.py
```

## Features Tested
- Privacy settings validation
- Time calculations
- Access control logic

## Test Files
- `test_privacy_feature.py` - Core functionality test
- `privacy-controls.test.js` - Integration tests
- `privacy-controls-frontend.test.jsx` - UI component tests
- `test_privacy_controls_backend.py` - API endpoint tests
